# Dropline Duel

Connect-four against a minimax alpha-beta AI with a live search-depth slider and a visible evaluation bar.

**Status: early scaffold.** The repository currently contains the Vite + React + TypeScript project shell with a title screen; the game and AI described above are not implemented yet. `PLAN.md` describes the intended implementation.

## Planned

- Classic connect-four rules on a 7×6 board
- Minimax search with alpha-beta pruning and an adjustable depth slider
- Evaluation bar showing the AI's assessment of the position

## Run

```bash
npm install
npm run dev      # Vite dev server
npm test
npm run build
```
